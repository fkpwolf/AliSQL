# Building AliSQL Debian 12 Packages

This guide explains how to build optimized, size-efficient Debian 12 (Bookworm) packages for AliSQL.

## Quick Start

### Prerequisites

You need a Debian 12 or compatible system (Ubuntu 22.04+ also works) with:
- At least 4GB RAM (8GB recommended)
- At least 20GB free disk space
- Internet connection for downloading dependencies

### Build with Default Optimizations

The easiest way to build optimized packages:

```bash
cd packaging
./build-debian12-package.sh --install-deps
```

This will:
1. Install all required build dependencies
2. Configure CMake for Debian 12
3. Build optimized packages (excluding debug symbols and test suites)
4. Create an installation helper script

## Package Size Optimization

The build script implements several optimizations to keep package sizes small:

### 1. **No Debug Packages** (Default)
Debug symbol packages can be 10x larger than the main binaries. They are skipped by default.

To include debug packages:
```bash
./build-debian12-package.sh --with-debug
```

### 2. **No Test Packages** (Default)
The MySQL test suite is large and only needed for development/testing.

To include test packages:
```bash
./build-debian12-package.sh --with-tests
```

### 3. **Minimal Build Configuration** (Default)
Excludes:
- Unit tests
- Embedded server
- Unused storage engines

For a full build:
```bash
./build-debian12-package.sh --full-build
```

## Build Options

### Command-line Options

```bash
./build-debian12-package.sh [OPTIONS]

OPTIONS:
    -h, --help              Show help message
    -i, --install-deps      Install build dependencies
    --with-debug            Include debug packages
    --with-tests            Include test packages
    --full-build            Disable all optimizations
```

### Environment Variables

```bash
# Specify Debian release codename
DEB_CODENAME=bookworm ./build-debian12-package.sh

# Build commercial edition (requires license)
DEB_PRODUCT=commercial ./build-debian12-package.sh

# Custom build directory
BUILD_DIR=/tmp/alisql-build ./build-debian12-package.sh
```

## Package Types

The build produces several packages:

### Core Packages (Always Built)

1. **mysql-community-server** - MySQL server binaries
2. **mysql-community-client** - MySQL client tools
3. **mysql-common** - Common files shared between packages
4. **libmysqlclient21** - Client libraries
5. **libmysqlclient-dev** - Development headers

### Optional Packages (Size-Optimized Build Excludes)

6. **mysql-community-test** - Test suite (large, ~500MB)
7. **mysql-community-server-debug** - Debug binaries (very large)
8. **mysql-*-dbgsym** - Debug symbols (very large)

## Installation

After building, packages will be in the parent directory:

```bash
# Option 1: Use the generated install script
cd ..
./install-alisql-packages.sh

# Option 2: Install manually
sudo dpkg -i *.deb
sudo apt-get install -f  # Fix any dependency issues

# Option 3: Install specific packages only
sudo dpkg -i mysql-common_*.deb \
             mysql-community-client_*.deb \
             mysql-community-server_*.deb
```

## Starting MySQL

After installation:

```bash
# Start the service
sudo systemctl start mysql

# Enable auto-start on boot
sudo systemctl enable mysql

# Check status
sudo systemctl status mysql

# Secure the installation
sudo mysql_secure_installation
```

## Troubleshooting

### Build Fails with Missing Dependencies

```bash
# Manually install dependencies
sudo apt-get update
sudo apt-get build-dep mysql-server

# Or use the script
./build-debian12-package.sh --install-deps
```

### CMake Configuration Errors

Make sure you're running from the repository root:
```bash
cd /path/to/AliSQL
./packaging/build-debian12-package.sh
```

### Package Size Too Large

Use all optimization flags:
```bash
SKIP_DEBUG_PACKAGES=1 \
SKIP_TEST_PACKAGES=1 \
MINIMAL_BUILD=1 \
./build-debian12-package.sh
```

### Debian/Rules File Not Found

The debian/ directory is generated by CMake. If missing:
```bash
# Clean and rebuild
rm -rf debian/ CMakeCache.txt
./packaging/build-debian12-package.sh
```

## Advanced Configuration

### Custom Compiler Flags

Edit `packaging/deb-in/rules.in` to add custom compiler flags:

```cmake
-DCMAKE_C_FLAGS="-O3 -march=native"
-DCMAKE_CXX_FLAGS="-O3 -march=native"
```

### Debian Package Control

Edit `packaging/deb-in/control.in` to modify:
- Package dependencies
- Package descriptions
- Conflicts/Replaces rules

### Custom Package Names

Modify the following in `packaging/deb-in/CMakeLists.txt`:
```cmake
SET (DEB_PRODUCTNAME "custom-name")
```

## Size Comparison

Typical package sizes:

| Configuration | Total Size | Notes |
|---------------|------------|-------|
| **Minimal** (default) | ~150-200MB | No debug, no tests |
| With tests | ~500-700MB | Includes test suite |
| With debug symbols | ~1-2GB | Includes all debug info |
| Full build | ~2-3GB | Everything included |

## Debian 12 Specific Notes

### Compatibility
- Built packages work on Debian 12 (Bookworm) and later
- Compatible with Ubuntu 22.04+ (Jammy and later)
- Uses system libraries when possible (OpenSSL, zlib)

### System Requirements
- Debian 12 uses debhelper 13+ 
- Requires systemd for service management
- Default MySQL socket: `/var/run/mysqld/mysqld.sock`

### AppArmor Support
If using Ubuntu, AppArmor profiles are automatically included and configured.
